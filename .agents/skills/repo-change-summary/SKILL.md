# Сводка изменений в репозитории

Запустите `scripts/summarize.py --repo <путь-к-репозиторию>` через Python 3.9+.
Путь к скрипту считайте относительно папки этого навыка. Скрипт только читает Git,
выдает JSON в stdout и не читает содержимое файлов.

По полученному JSON составьте короткую сводку на русском:

- `staged` - файлы, подготовленные к коммиту;
- `unstaged` - изменения, еще не добавленные в коммит;
- `untracked` - новые файлы вне учета Git;
- проверки - только фактически выполненные в этом запросе. Скрипт их не запускает.

Один файл может быть и в staged, и в unstaged: не теряйте одно из состояний.
При ошибке Git сообщите ее, не выдавайте пустой результат за отсутствие изменений.
Если просят объяснить смысл правок, отдельно прочитайте только относящийся к задаче diff,
не выводя секреты и персональные данные. Имена файлов сами по себе не доказывают поведение кода.

Ответ дайте в чате. Файл результата создавайте только по просьбе пользователя.
Не изменяйте исходники, индекс и историю Git; не делайте commit, push или сетевые запросы.
